# 1. 목적과 적용 범위

완성된 스크리닝 리포트 한 건을 읽고, **그 리포트가 잘 작성되었는지**를 0–100점과
`pass`/`revise`/`blocked` 판정으로 기록한다.

이 루브릭은 **정답지 대조가 아니다.** 실제 손해사정서(ground truth)와 비교하는
평가는 격리된 Unit 11 서비스의 몫이고 로컬에서는 이용할 수 없다. 여기서 하는 일은
리포트를 루브릭과 대조하는 것뿐이며, 채점자는 `source-cases/`·`data/ground_truth/`를
어떤 이유로도 열지 않는다.

**채점자가 볼 수 없는 것:** 원본 의무기록, 상위 단계 계약 파일. 따라서 "리포트가
빠뜨린 사실"과 "사건 자료에 애초에 없던 사실"을 채점자는 직접 구분할 수 없다.
이 한계는 §4 침묵 대 명시 원칙으로 처리한다. 입력을 넓혀서 해결하지 않는다.

# 2. 채점 입력

| 입력 | 필수 | 용도 |
| --- | --- | --- |
| `screening_report*.md` | 필수 | 채점 대상 본문 |
| `screening_report.json` | 선택 | 섹션 역할·`evidence_references` 교차 확인. 없어도 채점은 성립해야 한다 |
| 리포트 말미 **출처 블록** (`E1 - 진단서 (DOC_012) - p.1` 형식) | 사실상 필수 | A3 근거 등급 판정의 유일한 재료 |

출처 블록이 없는 리포트는 A3를 `applicable: false`로 두지 않는다. 근거 표기가
없다는 것 자체가 A3의 낮은 수준이다(§5 A3 앵커 0–1 참조).

# 3. 섹션 역할 매핑

이 저장소에는 서로 다른 세 가지 렌더 형태가 존재한다(2026-08-21 확인). 채점은
**제목 문자열이 아니라 역할**을 본다.

| 역할 | 10섹션형(현행, `rubric_test/`) | 8섹션형(`outputs/CASE_021/`) | 7섹션형(`templates/screening-report.md`) |
| --- | --- | --- | --- |
| R1 사건·공통 의료정보 | 1. 사고와 공통 의료정보 | 1. 사건 개요 | 1. 사건 개요 |
| R2 사건유형 판정 | 2. 사건유형 병렬 판정 / 3. 유형별 추가정보와 접수 상태 | 1에 포함 | 1에 포함 |
| R3 의료변수 확보 현황 | 4. 의료영역 확보 현황 | 1·3에 분산 | 없음 |
| R4 필요서류 상태 | 5. 필요서류 체크리스트 | 5. 추가 필요 자료 | 5. 추가 필요 서류 |
| R5 충돌·불일치 | 6. 중요 충돌과 유형 판정 영향 | 4. 문서 정합성 검토 | 4. 문서 간 불일치 |
| R6 미확인 항목 | 7. 주요 미확인 항목 | 5에 포함 | 없음 |
| R7 약관·요건 상태 | 8. 관련 약관과 요건 자료상태 | 3에 포함 | 없음 |
| R8 보험사 응답 | 9. 보험사 응답 | 2. 보험사 판단 | 2. 보험사 판단 |
| R9 검토 안내 | 10. 검토 시 유의사항 | 6·7 | 6·7 |

해당 형태가 애초에 갖지 않는 역할(7섹션형의 R3·R6·R7)은 **감점 사유가 아니다.**
그 역할이 요구하는 내용을 다른 역할이 담고 있으면 그것으로 충족된 것으로 본다.

# 4. 침묵 대 명시 원칙 (이 루브릭의 중심 규칙)

근거: 핵심변수 문서의 표현 원칙 — "자료가 부족한 경우 '기왕력 없음'으로 단정하지
않고, '제공된 자료에서 확인되는 기왕력 없음'으로 표현한다."

| 리포트의 상태 | 채점 |
| --- | --- |
| 값이 기재되어 있다 | 만점 취급 |
| 값이 없고, **범위를 한정한 부재 선언**이 있다 | 만점 취급 |
| 값이 없고, 아무 언급도 없다 | 감점 |
| 값이 없는데 **무한정 단정**했다("기왕력 없음") | 게이트 G3 |

현행 리포트가 실제로 쓰는 부재 선언 문형(그대로 인정한다):

- `라우팅 우선순위상의 어떤 출처도 이 항목을 기재하지 않았습니다`
- `사건유형별 추가 확인 출처를 열람했으나 이 항목을 기재한 내용이 없습니다`
- `기재가 없다는 점을 부정 소견으로 보지는 않습니다`
- `확인 불가` (항목명과 함께 명시된 경우)
- `제공된 자료에서 확인되는 …없음`

**부재를 제대로 선언한 리포트를 감점하지 않는다.** 이 루브릭에서 벌점을 받는 것은
모르는 것을 아는 척한 리포트와 모른다는 사실조차 말하지 않은 리포트다.

# 5. 채점 축

각 축은 0–4로 채점하고, 적용 가능한 축마다 **리포트 원문 인용을 최소 1개** 남긴다.
인용 없는 점수는 결과 스키마가 거부한다.

## A1 구조 완결성 — 가중치 10

**정의:** §3의 역할들이 실제로 채워져 있는가. 빈 껍데기 섹션, 플레이스홀더,
잘린 문장이 없는가.

| 수준 | 기준 |
| --- | --- |
| 4 | 해당 형태의 모든 역할이 존재하고, 각 역할이 실제 내용을 담고 있다. 미기재 항목도 부재 선언 형태로 채워져 있다 |
| 3 | 모든 역할이 존재하나, 한 역할이 형식적으로만 채워져 있다(예: 항목명만 있고 값도 부재 선언도 없음) |
| 2 | 역할 하나가 통째로 비었거나, 플레이스홀더·미완성 문장이 남아 있다 |
| 1 | 역할 두 개 이상이 비었다 |
| 0 | 리포트로 읽을 수 없는 상태다 |

## A2 핵심변수 커버리지 — 가중치 25

**근거:** 핵심변수 문서의 8개 도메인 × A/B/C/D 등급.

**A등급 변수(리포트에 반드시 값 또는 부재 선언이 있어야 하는 것):**

| 도메인 | A등급 변수 |
| --- | --- |
| 진단 | 주진단명 |
| 진단 근거 | 진단서상 진단명 |
| 치료 | 주요 치료 유형(수술/시술/약물/보존), 수술·주요 시술 시행 여부 |
| 임상경과 | 최종 임상경과(호전/유지/악화/사망), 현재 치료상태(치료 중/종료/추가 예정) |
| 기왕력 | 환자 자가응답 기왕력(있음/없음/모름) |
| 장해 | 장해 관련 진단명, 장해 유형(지체·절단/관절/기능/기타) |

**B등급 변수(리포트가 그 기록의 존재를 스스로 밝힌 경우에 요구):** 사고일 또는
진단일, 진단 부위·좌우·진료과·상병계통·진단코드, 확진/임상적 추정 구분, 구체적
수술·시술명, 주요 치료 시행일·치료기간, 입원 여부·입원기간, 주요 증상·검사상 변화,
추가 치료·재수술 여부, 절단 수준 또는 ROM 또는 객관적 기능검사, 기존 장해평가 자료.

**C·D등급 변수는 있으면 가점 요소가 아니고, 없어도 감점하지 않는다.** 다만 D등급
영역(최종 장해율 산출, 증세고정 판단)을 리포트가 스스로 **판단**했다면 게이트 G2다.
기존 자료에 기재된 장해율을 **옮겨 적은 것**은 D등급 침범이 아니다 — 옮긴 것임이
문면에서 드러나야 한다.

| 수준 | 기준 |
| --- | --- |
| 4 | A등급 전 항목이 값 또는 범위 한정 부재 선언으로 처리되어 있고, 사건이 요구하는 B등급 변수도 대부분 같은 방식으로 처리되어 있다 |
| 3 | A등급 전 항목이 처리되어 있고, B등급 일부가 언급 없이 빠져 있다 |
| 2 | A등급 항목 1–2개가 값도 부재 선언도 없이 비어 있다 |
| 1 | A등급 항목 3개 이상이 침묵 상태다 |
| 0 | 의료변수 정리가 사실상 없다 |

## A3 근거 등급 — 가중치 15

**근거:** 의무기록 우선순위 문서.

| 등급 | 문서 |
| --- | --- |
| A | 진단서, 수술·시술 기록지, 기존 장해진단서·신체감정서 |
| B | 외래 진료기록, 최종 진료기록, 주요 검사결과지, 입·퇴원 요약, 응급실 기록(외상기전·초진 상태가 쟁점이면 상승) |
| C | 처방·치료내역, 간호기록, routine 검사, 비용 관련 문서 |

원칙: 검사결과지는 문서 전체를 A로 보지 않는다. 다만 현재 진단을 직접 뒷받침하는
핵심 검사결과(골절의 영상 판독, 종양의 병리결과)는 우선 인용 대상이며, 원본 영상보다
**판독결과지**를 우선한다.

법률의견서·보험사 안내문 등 의무기록이 아닌 문서는 이 등급 체계 밖이다. 배상책임·
보험사 판단 관련 서술의 근거로 쓰인 경우 감점하지 않는다.

| 수준 | 기준 |
| --- | --- |
| 4 | 주요 사실 서술마다 출처 태그가 붙어 있고, 진단·치료·장해 관련 핵심 주장이 A등급 문서에 귀속된다 |
| 3 | 대부분 A·B등급에 귀속되나, 일부 핵심 서술이 B등급에만 의존한다 |
| 2 | 핵심 주장 하나 이상이 C등급 문서에만 근거하거나, 출처 태그가 붙지 않은 사실 서술이 눈에 띈다 |
| 1 | 출처 표기가 산발적이어서 어느 문서에서 온 값인지 대부분 추적되지 않는다 |
| 0 | 출처 표기가 없다 |

## A4 유형 판정·필요서류 정합 — 가중치 20

**근거:** 유형별 주 필요서류 문서.

| 유형 | 주 필요서류 |
| --- | --- |
| 개인보험(후유장해진단금) | 진단서, 초진기록지, 수술기록지, 영상판독지 |
| 교통사고 | 위 4종 + 진료비영수증, 진료비세부내역서, 약제비납입확인서 |
| 배상 | 위 7종 + 경과기록지, 검사결과지 |
| 근재보험(산재) | 배상과 동일 9종 |

유형 판정은 **사고내용·진단명·수술명**에서 나온다. 하나의 사건이 복수 유형에
해당할 수 있고(예: 사다리 추락 → 산재·근재·개인보험 병렬), 병렬 판정 자체는 정상이다.
**해당 없음을 단정하지 않고 '불확실'로 남기는 것은 감점이 아니라 정확한 처리다.**

| 수준 | 기준 |
| --- | --- |
| 4 | 유형 판정이 사고경위·진단·청구담보 기재와 정합하고, 판정된 유형별 필요서류가 보유/미확인으로 전부 대조되어 있다 |
| 3 | 유형 판정은 정합하나 필요서류 대조에 누락 서류종이 있다 |
| 2 | 유형별 필요서류 대조가 없거나, 유형 판정 근거가 제시되지 않았다 |
| 1 | 유형 판정이 사건 기재와 부분적으로 어긋난다 |
| 0 | 유형 판정과 청구담보가 서로 모순된다 → 게이트 G5도 함께 검토 |

## A5 쟁점·판단 실행가능성 — 가중치 15

**정의:** 읽는 사람이 다음에 무엇을 해야 하는지가 리포트에서 나오는가.

의료자문의 기본 확인 흐름(진단 → 주요 수술·치료 → 이후 경과 이상 여부 → 최종 상태
→ 이를 뒷받침하는 핵심 검사)이 쟁점 정리에 반영되어 있는지 본다. 심화평가 trigger
(감염·CRPS 등 중대한 합병증, 예상 밖 장기치료)가 자료에 있는데 쟁점으로 올라오지
않았다면 감점.

| 수준 | 기준 |
| --- | --- |
| 4 | 쟁점마다 리포트 내 사실에 묶인 근거가 있고, 검토 요청이 손해사정사/의사/법률전문가로 적절히 라우팅되며, 무엇을 확인하면 쟁점이 해소되는지가 적혀 있다 |
| 3 | 쟁점과 라우팅은 적절하나, 일부 요청이 무엇을 확인해야 하는지까지 내려가지 않았다 |
| 2 | 쟁점이 나열되어 있으나 근거 연결이나 라우팅이 없다 |
| 1 | 쟁점이 사건 사실과 거의 무관하거나 일반론에 그친다 |
| 0 | 쟁점·검토 안내가 없다 |

## A6 내부 일관성 — 가중치 15

**정의:** 리포트 안에서 날짜·진단명·부위·좌우·기간·금액이 서로 어긋나지 않는가.
그리고 리포트가 선언한 충돌이 실제 충돌인가.

좌우(좌/우측) 불일치는 C등급 변수지만 **장해 판정의 전제**이므로 이 축에서는
중대 불일치로 다룬다.

| 수준 | 기준 |
| --- | --- |
| 4 | 섹션 간 사실이 일치하고, 선언된 충돌은 모두 실제 상반 기재이며 출처가 양쪽 다 제시된다 |
| 3 | 사실은 일치하나 충돌 서술의 출처 제시가 한쪽뿐이다 |
| 2 | 섹션 간 사소한 불일치가 있으나 리포트가 그 사실을 인지·표시하고 있다 |
| 1 | 섹션 간 사실이 어긋나는데 리포트가 인지하지 못한다 → 게이트 G4 |
| 0 | 핵심 사실(진단명·부위·사고일)이 서로 다른 값으로 여러 번 나온다 |

# 6. 게이트

게이트는 점수와 독립이다. 하나라도 걸리면 `weighted_total`과 무관하게 판정은
`blocked`이고, 점수는 그대로 함께 기록한다. 게이트를 걸 때는 **문제가 된 문장을
인용**한다(스키마 강제).

| 게이트 | 발동 조건 | 확인 방법 |
| --- | --- | --- |
| G1 금지표현 | `templates/forbidden-expressions.md`의 리터럴, 또는 그 취지의 무완충 패러프레이즈("당연히 지급되어야 마땅하다") | `python tools/dao.py check-forbidden-expressions <경로>`로 결정론적 바닥을 잡고, 의미 패스를 별도로 수행. `clean: true`가 의미 패스를 면제하지 않는다. `NOT_FOUND`/`NO_TEMPLATE`는 통과가 아니라 설정 실패다 |
| G2 자문의 판단영역 침범 | 리포트가 스스로 최종 장해율을 산출하거나, 증세고정을 판단하거나, 인과관계를 단정 | 기재된 장해율을 옮긴 것은 해당 없음. "산출"과 "인용"을 문면으로 구분 |
| G3 무한정 부재 단정 | 자료 범위를 한정하지 않은 부재 단정("기왕력 없음", "합병증 없음") | §4의 부재 선언 문형이면 해당 없음 |
| G4 섹션 간 사실 모순 | 같은 사실이 두 섹션에서 다른 값인데 리포트가 인지하지 못함 | 날짜·진단명·부위·좌우·기간·금액 |
| G5 유형·담보 모순 | 판정된 사건유형과 청구담보·사고경위가 양립 불가 | '불확실' 표기는 모순이 아니다 |

# 7. 점수 계산

```
weighted_total = 100 × Σ_적용가능(raw_i ÷ 4 × weight_i) ÷ Σ_적용가능(weight_i)
```

소수 첫째 자리까지 기록한다.

**N/A 처리:** 사건이 애초에 관여하지 않는 축은 `applicable: false` + `na_reason`으로
기록하고 분모에서 뺀다. 축을 배열에서 빼는 것은 스키마가 거부한다 — 낮은 축을
분모에서 조용히 없애는 경로를 막기 위해서다.

**판정:**

| 조건 | verdict |
| --- | --- |
| 게이트 1개 이상 발동 | `blocked` |
| 그 외 `weighted_total >= 80` | `pass` |
| 그 외 | `revise` |

# 8. 채점 결과 기록

리포트 1건당 `screening_rubric_result*.json` 1건.
`schemas/screening_rubric_result.schema.json` 준수.

- 파이프라인 케이스: `python tools/dao.py write-contract CASE_ID
  screening_rubric_result_v1.json --data-file <경로> --schema-name
  screening_rubric_result.schema.json --held-by screening-rubric --run-id RUN_ID`
- `outputs/` 밖의 단독 리포트: 리포트 옆에 쓰고
  `python tools/validate_output.py <경로>`로 검증

`target_report_sha256`은 채점한 파일의 실제 해시를 복사한다. 기억으로 적지 않는다.

# 9. 채점자가 하지 말아야 할 것

- 사건을 다시 판단하지 않는다. 채점 대상은 리포트지 사건이 아니다.
- 장해율을 계산하거나 증세고정을 판단하지 않는다. 리포트에 금지한 것을 채점자가
  하면 안 된다.
- 원본 자료·상위 계약·정답지를 열지 않는다.
- 리포트가 범위를 한정해 부재를 밝힌 항목을 감점하지 않는다.
- 인용 없이 점수를 주지 않는다.
